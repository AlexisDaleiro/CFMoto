# Asset Requirements

Inventario priorizado para exploración, demo y producción. Ningún asset online se presume autorizado.

## Required

### Brand

- Brand book vigente, mercado/fecha y contacto aprobador.
- Logo maestro vectorial y variantes positivas/negativas/monocromas; clear space, tamaño mínimo y reglas sobre fotografía.
- Definición oficial de CFMOTO Cyan y perfiles de color para digital/print.
- Tipografías corporativas con archivos, licencia web/app, pesos permitidos, territorios y fallback; o confirmación escrita de que no existe obligación tipográfica.
- Reglas para slogans, Racing/co-branding, distribuidores y marcas de componentes.

### Producto y datos

- Catálogo Uruguay por modelo, variante, model year, color y categoría con IDs estables.
- Especificaciones oficiales locales, unidad, fuente, fecha y owner.
- Precio/estado/disponibilidad y disclaimer cuando se vaya a mostrar.
- Cutout de alta resolución por producto/color: 3/4 consistente, lateral y frente cuando exista; fondo/transparencia y sombra separada ideales.
- 3–5 key facts y claims aprobados por producto.
- Estado correcto de 450SR, 800MT Touring, 700CL-X Heritage, ZFORCE 1000 Sport, CFORCE 450L y UFORCE 800; los dos últimos siguen `CLIENT VALIDATION REQUIRED`.

### Comercial/local

- Locations verificadas: NAP, coordenadas, horarios, capacidades, categorías y contactos.
- Reglas/eligibilidad de Cotizar y Test Ride; teléfono/WhatsApp y privacidad aprobados.
- Identidad legal, garantías/service y claims de red autorizados.

### Derechos y accesibilidad

- Owner, fuente, licencia, canales, territorio, duración, transformaciones, crédito y expiración por asset.
- Consentimiento de personas/localizaciones/eventos y marcas de terceros cuando aplique.
- Texto alternativo o datos suficientes para redactarlo correctamente.
- Masters sin copy embebido y con focal point/safe zones o crops desktop/tablet/mobile.

## Strongly recommended

- Campaign hero con versiones landscape/portrait y key visual sin texto.
- 450SR: estudio, pista, dinámica, detalle de carenado/motor/freno/TFT y galería coherente.
- MT/Adventure: ruta, paisaje, ergonomía y equipo, incluyendo contexto regional autorizado si existe.
- CFORCE: recreación/utility, terreno, racks, suspensión/traction y producto aislado.
- UFORCE: cabina, caja, trabajo real, ocupantes y detalle funcional.
- ZFORCE: acción, suspensión/protección, cabina y contexto sport.
- Racing: archivo actual con fecha, piloto/equipo/circuito, resultados/claims y derechos.
- Technology: macro, piezas, iluminación, TFT/conectividad y diagramas oficiales por modelo.
- Community: eventos/owners/entregas/rides locales con releases y captions.
- Dealer/service: exteriores, interiores, equipo/personas y señalética consistente.
- Guía de color grading y selección fotográfica para mantener continuidad entre assets globales/locales.
- SVG/diagramas oficiales de features y pictogramas técnicos si existen.

## Premium enhancement

- Film hero breve con master horizontal/vertical, poster frame, subtítulos/transcript y mezcla sin depender de audio.
- Shoot local dirigido: rutas/territorios uruguayos, ownership y red.
- Rotación/3D o renders configurables con permiso por modelo/color y fallback estático.
- Sonido únicamente para piezas voluntarias; licencia separada y experiencia completa en silencio.
- Telemetría real o material de túnel de viento/pruebas, con fuente y autorización.
- Fotografía aérea/circuito/localización con permisos.

## Demo package mínimo

Para evaluar dirección sin fingir un catálogo completo:

- Logos y cyan aprobados para propuesta.
- Un cutout y un lifestyle por cada vehículo demo representativo.
- Set rico de 450SR para hero + estudio de ficha.
- Al menos un set usable para CFORCE, UFORCE y ZFORCE.
- Una historia/asset por Racing, Adventure y Technology; Community puede usar módulo condicional solo si existe material real.
- Datos key facts validados y disclaimer de propuesta.
- Documento de derechos que marque `reference only`, `proposal-cleared` o `production-cleared`.

## Production package

Además del demo: todas las variantes activas, crops finales, galería, documentación/manuales, OG/social, ubicaciones, legal, campañas con expiración, metadata/alt, transcript/captions y owner/cadencia. Un asset sin derecho o relación correcta con producto falla el content gate.

## Matriz de seguimiento sugerida

| Campo                             | Ejemplo de estado                           |
| --------------------------------- | ------------------------------------------- |
| Asset ID                          | estable, no filename libre                  |
| Vehicle/variant/year/color        | relación exacta                             |
| Purpose                           | hero, listing, feature, gallery, OG         |
| Source/owner                      | contacto responsable                        |
| Rights status                     | unknown / reference / proposal / production |
| Allowed channels/territory/expiry | explícito                                   |
| Master quality                    | dimensiones, formato, perfil                |
| Crops/focal point                 | desktop / tablet / mobile                   |
| Alt/caption/credit                | completos                                   |
| Verification                      | status + date                               |

## Acceptance gate

No pasa a producción ningún asset con derechos desconocidos, variante dudosa, calidad insuficiente, texto embebido evitable o ausencia de fallback crítico. Video/3D nunca bloquean; logo, catálogo, datos, cutouts, derechos y conversión sí.
